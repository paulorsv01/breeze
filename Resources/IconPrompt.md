# App icon

Generated using the built-in imagegen tool, then packaged into ICNS with macOS sips and iconutil. The menu-bar template remains a monochrome asset.

## Prompt

Use case: logo-brand
Asset type: macOS application icon for Breeze, a menu bar fan-control utility
Primary request: A polished minimal macOS app icon showing a flowing three-blade fan with a subtle breeze motion, recognizable at small sizes.
Style/medium: refined softly dimensional glass and satin material, crisp silhouette, restrained highlights.
Composition/framing: one centered icon, square image, rounded-square teal-to-deep-blue tile on transparent surrounding background, generous macOS icon padding. Fan blades in pale mint and white. No text, letters, badges, mockup, or watermark.

Transparent background requested.
